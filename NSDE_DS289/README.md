# DS 289 Numerical Solution of Differential Equations

Coded questions of the three assignments. The question sheet of each assignment is in its folder (`question.pdf`).

| Assignment | Questions | Topics |
|---|---|---|
| [Assignment1](Assignment1/) | 2, 3, 4, 5 | explicit Euler, Adams-Bashforth, RK4, implicit Euler for a stiff equation, tridiagonal solver |
| [Assignment2](Assignment2/) | 1, 4, 5 | Laplace equation with a banded direct solver, explicit and implicit diffusion, Jacobi iteration |
| [Assignment3](Assignment3/) | 1, 4 | Burgers' equation with upwind and central schemes, finite elements for a bar |

Each question folder has `src/`, `input/`, `output/`, a `Makefile` and `run.sh`: `make && ./run.sh`.
