# IISc course assignments

Coding assignments from three courses at the Indian Institute of Science.

| Folder | Course | Topics |
|---|---|---|
| [Parallel_Programming](Parallel_Programming/) | Parallel Programming | MPI matrix multiplication (Cannon, SUMMA), shortest paths on the GPU (CUDA), hybrid CPU + GPU sort |
| [Intro_Scalable_Systems](Intro_Scalable_Systems/) | DS 221 Introduction to Scalable Systems | sparse and dense matrix products, triangle patterns in graphs, OpenMP histogram, MPI merge sort |
| [NSDE_DS289](NSDE_DS289/) | DS 289 Numerical Solution of Differential Equations | ODE schemes, diffusion, Laplace, Burgers' equation, finite elements |

Each assignment folder contains:

```
README.md   problem, approach, how to run, results
src/        source code
input/      input files and parameters (large inputs are generated by the code)
output/     logs and result tables
scripts/    Slurm job scripts (parallel assignments), run.sh (numerical methods)
Makefile
```

Requirements: `g++` and `make`; `python3` with numpy and matplotlib for checks and plots; an MPI
compiler (`mpic++`, Open MPI 4) for the MPI codes; `nvcc` (CUDA 12) and an NVIDIA GPU for the GPU codes.
The job scripts use Slurm; adjust the partition names and `module load` lines for your cluster.
